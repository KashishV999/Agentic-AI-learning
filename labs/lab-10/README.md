# Lab 10: Media Data URI Library With Codex

## Why This Lab Exists

This lab is for learning how to work with a coding agent instead of only calling an API directly. The intended goal is to build a small media Data URI library with tests, while practicing Codex CLI setup, agent steering, and test-driven development.

- Why coding-agent work is different from normal prompting because I have to guide, review, and verify code changes.
- How `AGENTS.md` gives project context to the agent before it starts writing code.
- Why test-driven development is a good fit for agent workflows.
- How this lab connects multimodal file handling to a practical utility library.
