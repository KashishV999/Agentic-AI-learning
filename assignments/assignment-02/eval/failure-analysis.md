1. Failure 1: Too strict on keyword matching
Not really "wrong" , the prompts were tight, so the LLM couldn't hallucinate much. But scoring sometimes dropped points if a job post used an exact word (like an API name) that my resume didn't use, even if I had the skill. Fair enough though , real ATS tools do the same thing. Fix: make the advisor check for similar skills, not just exact word matches.
2. Failure 2: Unfair to small companies
Legitimacy checks use web search, so small or new companies with little online presence sometimes got scored as less trustworthy  not because they're bad, just because there's less info about them online. Fix: treat "not much info found" differently from "looks suspicious."

Overall summary
The system is good at staying accurate  schemas and search tools keep it from making things up, and it pulls resume/job info reliably.
